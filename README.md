Clean Supplies Website

This is a simple business website built to promote and advertise household cleaning products for a local business.

Features
- Product display section
- Business information
- Clean and simple layout
- Responsive design (works on mobile and desktop)

Built With
- HTML
- CSS

Purpose
The goal of this project is to practice front-end web development skills while creating a real-world business website.
